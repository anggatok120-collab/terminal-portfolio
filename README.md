## 🌟 Overview

**Terminal Portfolio** is a lightweight, interactive shell-inspired Web UI designed to showcase professional experience in Network Engineering, NOC (Network Operations Center), and Helpdesk Support. It mimics a Linux terminal interface with interactive commands, tab autocompletion, command history, and bilingual support.

### ✨ Key Features

- 🖥️ **Interactive Terminal Interface**: Real-time CLI prompt with command execution, custom block cursor animation, and command history.
- 🌐 **Bilingual Support (ID/EN)**: Instant toggling between Indonesian and English without reloading the page.
- ⚡ **Zero External JS Dependencies**: Built entirely with Vanilla HTML5, CSS3, and JavaScript for blazing-fast load times.
- ⌨️ **Keyboard Shortcuts & Utilities**:
  - `Tab`: Auto-complete available commands.
  - `Arrow Up` / `Arrow Down`: Navigate command history.
  - `Ctrl + L`: Clear terminal screen.
- 📱 **Responsive & Mobile Friendly**: Includes quick-click command chips for touchscreen devices.
- 🎨 **Sleek Dark Theme**: Styled with JetBrains Mono font, smooth neon accents (`#a3e635`), and subtle window shadow effects.

## 🛠️ Available Commands

Users can interact with the terminal by typing any of the following commands:

| Command | Description |
| :--- | :--- |
| `help` | Displays a list of available commands and instructions |
| `whoami` | Shows professional summary and background |
| `skills` | Lists technical competencies (Network Monitoring, MikroTik, Linux, etc.) |
| `experience` | Displays work history & NOC/Helpdesk roles |
| `education` | Displays educational background |
| `projects` | Shows featured portfolio projects & GitHub links |
| `contact` | Displays contact information, social links, and email |
| `resume` | Generates direct link to download CV / Resume |
| `ls` | Lists directory contents and available command paths |
| `netstat` | Displays network interface status simulation |
| `traceroute` | Simulates packet routing to key services |
| `date` | Displays current date and time |
| `clear` | Clears the terminal screen (`Ctrl+L`) |

## 🚀 Getting Started

### Prerequisites
You only need a modern web browser to view or test this project locally. No build tools or Node.js server required!

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/anggatok120-collab/terminal-portfolio.git
   cd terminal-portfolio
   ```

2. **Open in browser:**
   Simply double-click `index.html` or serve using any static file server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Or using Node npx serve
   npx serve .
   ```

3. Open `http://localhost:8000` in your browser.
